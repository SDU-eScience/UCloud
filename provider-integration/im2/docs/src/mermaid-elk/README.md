# Mermaid ELK layout

These files come from `@mermaid-js/layout-elk` version `0.1.7`.
They provide local orthogonal routing for the Mermaid diagrams.

Source package: https://registry.npmjs.org/@mermaid-js/layout-elk/-/layout-elk-0.1.7.tgz

The files under `dist/` are unchanged upstream assets.
`LICENSE` contains the package's MIT license.

The renderer bundles ELK.js and D3. Their licenses are included beside this file.
ELK.js source is available under EPL-2.0 at https://github.com/kieler/elkjs.
D3 source is available at https://github.com/d3/d3/tree/v7.9.0.
